# Images

Put photographs here (JPG or PNG), then replace the matching placeholder block in `index.html` with:

```html
<img src="images/your-photo.jpg" alt="Short description" style="width:100%;height:100%;object-fit:cover;display:block">
```

Suggested files:

- `alex-main.jpg` — main introduction photograph
- `tennis-action.jpg` — tournament or match photo
- `awards/` — trophies, medals, District Champion / MVP
- `music-recital.jpg` — concert photographs
- `friendship-circle.jpg` — volunteer photos (only with permission)
- `article-page23.jpg` — screenshot of the published page
- `fishing.jpg` — fishing photos
